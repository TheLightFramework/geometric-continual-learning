# Model card

## Identity and intended use

`reader-consolidated-79701`, 151,905,024 parameters. Research on modular residual geometry, restricted adaptation, preservation objectives and checkpoint lifecycle controls. Not an instruction-following assistant or production memory service.

The release artifact is the existing frozen default, not selected from the newer owner-checking study. See `artifacts/reader-consolidated-79701/MANIFEST.json` for exact configuration, topology and hashes. Optimizer moments, RNG state and historical training reservoirs are excluded. The tensor-only export is suitable for inference and fresh optimizer trials, **not exact resumption of formation**.

## Training and evaluation summary

Formation used FineWeb/Cosmopedia with 2,147,483,648 token exposures: 1,744,830,464 fresh and 402,653,184 revisited. Guidance added 33,554,432 targets, followed by restricted synthetic reading lessons and preservation-assisted consolidation. An exposure count is not the number of unique examples or a guarantee against train/test contamination in public corpora.

The earlier general interface evaluation reached 66.67% pooled, 2.08% minimum family, and 100% termination. This is why the model is not described as a dependable speaker. The strongest later results concern carefully bounded reading tasks. All seed-level results and transfer failures are in [Results](RESULTS.md).

## Risks and limits

It can confidently return a visible but wrong value, confuse queried owners, fail under unfamiliar wording, and continue incorrectly. UNKNOWN behavior is not reliable uncertainty calibration. Generated text can reflect biases, offensive content or inaccuracies from pretraining. Do not use for medical, legal, financial or safety-critical decisions, autonomous publication, or unattended high-impact actions.

No robust privacy, extraction-resistance, fairness or adversarial safety audit is provided. Training-source membership and benchmark overlap were not exhaustively audited. Hashes establish byte identity, not model honesty or safety.

## Architecture scope

The present model is a single decoder with modular geometric residual blocks. Historical two-stream invariance results from a different prototype do not transfer automatically. The current protected tensor subset is exact during bounded local updates; output preservation must be measured separately.
