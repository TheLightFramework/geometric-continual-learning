# Research priorities

## Highest-information next work

1. Compare canonical-only and construction-diverse owner-checking lessons with matched target exposure and a retention surface that includes previously correct unfamiliar wording. Use fresh owners/constructions and lock settings before confirmation.
2. Separately test two-record owner–relation–value binding with both record orders, both queries and balanced value assignments. Do not conflate this with recognizing a name in one note.
3. Add a genuinely distinct second skill. Compare stopping, unregularized fitting, generic-input KL, and explicit old-query preservation. Report retained/lost/recovered items and the cost of replay.
4. Build a conventional architecture control with matched parameters, preservation objective, preparation history, data and measured execution budget.

## Downstream, not already achieved

Persistent factual storage without records in the prompt; general membership/abstention; reversible corrections; multi-token factual values; longer continual sequences; limited-capacity allocation; selective growth/retirement supported by complete enough behavior contracts.

Growth and quantization deserve controlled ablations, not automatic inclusion. A geometric operation being mathematically defined is not evidence that it improves learning. There is no reason to start another large formation run before isolating the current access and binding failures.

## Contribution success criteria

A useful contribution may reproduce a failure, find a confound, reduce engineering cost, improve a matched baseline, or deliver a negative result. New metrics must be preregistered before fitting. Public test prompts are contaminated for new confirmation; generate fresh reservations. Do not report an average without its seed range, template floor and relevant churn.
